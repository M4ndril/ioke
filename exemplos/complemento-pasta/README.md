# Complemento de exemplo: Pasta de músicas / Music folder

**English.** An IOkê add-on that finds songs in a folder on your PC. It is the model for writing add-ons
(see `docs/COMPLEMENTOS.md`) and the end-to-end test of the add-on system. Only the Python standard library.

**Português.** Um complemento do IOkê que busca músicas numa pasta do seu PC. É o modelo para escrever
complementos (veja `docs/COMPLEMENTOS.md`) e o teste de ponta a ponta do sistema de complementos. Só a biblioteca
padrão do Python.

- `karaoke-complemento.json`: o manifesto / the manifest
- `complemento.py`: o programa / the program
- `karaoke_complemento.py`: o SDK (cópia de `sdk/python/`) / the SDK (copy of `sdk/python/`)
